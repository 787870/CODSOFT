# CodSoft Power BI Internship - Task 3

## 📊 Student Performance Dashboard

### 📝 Overview
This repository contains an interactive dashboard that supports academic performance analysis[cite: 1]. It was developed to help educational institutions analyze student academic performance and attendance[cite: 1]. 

### 🚀 Key Features
* **Data Modeling:** Imported student marks and attendance datasets[cite: 1], merging the `student-mat` and `student-por` files to create a unified data model.
* **KPIs & Metrics:** Engineered DAX measures to dynamically display attendance percentages and examination results[cite: 1], alongside average scores and total student counts.
* **Interactive Visualizations:** 
  * Analyzed subject-wise performance[cite: 1] using a scatter plot with trendlines to map cross-subject correlations (Math vs. Portuguese).
  * Created charts showing grade distributions[cite: 1] using a custom clustered column histogram.
  * Built an unsummarized Matrix visual to create a chart showing a topper list[cite: 1] sorted by highest final grades.
* **Advanced Filtering:** Added filters for academic categories[cite: 1], implementing cross-page synced slicers (Age, Study Time, Internet Access, and School) to allow seamless deep-dive analysis across the entire report.

### 🛠️ Tools & Technologies Used
* **Power BI Desktop**
* **Power Query Editor** (Data transformation and cleaning)
* **DAX** (Data Analysis Expressions for custom metrics)
* **Data Visualization Best Practices**
