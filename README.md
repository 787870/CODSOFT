# 🚀 CodSoft Power BI Virtual Internship

Welcome to my project repository for the **CodSoft Power BI Virtual Internship** (July 2026 Batch). 

This repository documents my journey to transform theoretical data knowledge into practical expertise by developing a series of professional, end-to-end business intelligence dashboards. Throughout this one-month internship, I am leveraging Power BI Desktop, Power Query (ETL), and Data Analysis Expressions (DAX) to solve diverse analytical problems across multiple industries.

## 🎯 Internship Objectives
To successfully complete this internship, I am tasked with building interactive dashboards that clean, model, and visualize complex datasets to support data-driven decision-making. While only three tasks are required for completion, my goal is to execute all five assigned projects to build a robust and versatile analytics portfolio.

## 📂 Project Directory (Tasks)

### ✅ [Task 1: Sales Performance Dashboard](./CODSOFT_TASKSNO_1)
* **Status:** Completed
* **Objective:** Developed an interactive dashboard to analyze retail sales performance across different products, regions, and time periods.
* **Key Skills:** Time-intelligence DAX, conditional formatting, data type locale translation, and interactive slicers.

### ✅ [Task 2: Employee Performance Dashboard](./CODSOFT_TASKSNO_2)
* **Status:** Completed
* **Objective:** Created a Power BI dashboard that monitors employee performance and workforce productivity to support HR decision-making.
* **Key Skills:** Data visualization, KPI card creation (Total Employees, Attendance Rate, Performance Score), interactive charts for department-wise comparisons, and dynamic slicers for department, designation, and reporting periods.

### ✅ [Task 3: Student Performance Dashboard](./CODSOFT_TASKSNO_3)
* **Status:** Completed
* **Objective:** Developed an interactive dashboard to analyze student academic performance and attendance across different subjects and demographic groups.
* **Key Skills:** Data merging & modeling, DAX measures (attendance percentage calculation), cross-page synced slicers, and advanced visualizations (histograms, scatter plots with trendlines, and unsummarized matrices).

### ⏳ Task 4: Customer Sales Dashboard
* **Status:** Planned
* **Objective:** Build an analytics dashboard focusing on customer demographics, purchasing patterns, repeat customer rates, and revenue segmentation.

### ⏳ Task 5: Financial Health Dashboard
* **Status:** Planned
* **Objective:** Develop a comprehensive financial dashboard with KPI cards for Net Profit, Expenses, and Profit Margin, including forecasting models for future revenue.

## 🛠️ Tech Stack & Tools
* **Data Visualization & Modeling:** Power BI Desktop
* **Data Transformation (ETL):** Power Query Editor
* **Calculations:** DAX (Data Analysis Expressions)
* **Version Control:** Git & GitHub
* **Data Sources:** CSV and Excel files sourced from public repositories (e.g., Kaggle, Maven Analytics)
